# Telegram-бот «Тайный Санта» (демо)

Бот для игры в Тайного Санту: организатор создаёт игру и рассылает ссылку-приглашение,
участники вступают и пишут пожелания, бот проводит жеребьёвку, рассылает пары
и даёт анонимно переписываться. Одновременно может идти сколько угодно игр.

**Стек:** Python 3.11+, aiogram 3, SQLite (aiosqlite), APScheduler.

## Возможности

**Организатор** (любой пользователь, создавший игру)
- создаёт игру: название, бюджет подарка, дата обмена;
- получает ссылку-приглашение (deep link), по которой вступают участники;
- видит список участников и может удалить любого;
- задаёт исключения — пары, которые не должны дарить друг другу (например, супруги);
- запускает жеребьёвку; после неё вступать в игру и менять состав нельзя;
- если по исключениям жеребьёвка невозможна, получает понятное сообщение
  (и список тех, кому по исключениям некого дарить).

**Участник**
- вступает по ссылке, вводит имя и пожелания, может их изменить
  (если жеребьёвка уже прошла, Санта получит обновлённую анкету);
- после жеребьёвки получает в личку, кому дарит, и его пожелания;
- анонимный чат через бота: можно написать подопечному и своему Санте, не раскрывая себя.
  Сообщения копируются ботом, поэтому отправитель не виден; у каждого есть кнопка «Ответить».
  Поддерживаются текст, фото, видео, стикеры и т. д.;
- напоминания за 3 дня и за 1 день до даты обмена.

**Жеребьёвка** — никто не дарит себе, исключения соблюдаются, результат случайный.
Задача решается как поиск совершенного паросочетания (алгоритм Куна) со случайным
порядком перебора: бот гарантированно находит пары, если они существуют, и честно
сообщает, если нет. Покрыта тестами, включая сверку с полным перебором на маленьких играх.

## Структура

```
config.py                 # тексты, часовой пояс, лимиты, время напоминаний
bot/
├── __main__.py           # точка входа: python -m bot
├── settings.py           # чтение .env
├── db.py                 # SQLite: игры, участники, исключения, пары
├── draw.py               # жеребьёвка (чистая функция, без Telegram)
├── reminders.py          # напоминания через APScheduler
├── views.py              # даты, ссылки-приглашения, тексты карточек
├── keyboards.py          # клавиатуры и callback data
├── states.py             # FSM-состояния сценариев
└── handlers/
    ├── common.py         # /start (в т. ч. по ссылке), /help, отмена сценария
    ├── organizer.py      # создание игры, участники, исключения, жеребьёвка
    ├── participant.py    # вступление, карточка участника, изменение анкеты
    └── chat.py           # анонимная переписка
deploy/secret-santa-bot.service  # unit-файл systemd
tests/test_draw.py               # тесты жеребьёвки
tests/test_reminders.py          # тесты расписания напоминаний
```

## Запуск локально

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Создайте `.env` по образцу и впишите токен:
   ```bash
   cp .env.example .env
   ```
4. Запустите бота:
   ```bash
   python -m bot
   ```

Как проверить в одиночку: создайте игру, откройте ссылку-приглашение со своего аккаунта
и попросите двух друзей сделать то же самое (для жеребьёвки нужно минимум 3 участника).

Тесты:
```bash
pip install -r requirements-dev.txt
python -m pytest
```

## Настройка

Всё меняется в `config.py`:

- `IS_DEMO = False` — убрать пометку «демо» из приветствия;
- `TIMEZONE` — часовой пояс, по которому считаются даты и напоминания;
- `MIN_PARTICIPANTS` — минимум участников для жеребьёвки;
- `REMINDER_DAYS`, `REMINDER_HOUR` — за сколько дней напоминать и не раньше какого часа;
- `MAX_*_LEN` — ограничения длины названия, бюджета, имени и пожеланий;
- `TEXTS` — все тексты и подписи кнопок.

Напоминания проверяются раз в час и сразу при запуске бота. Отправленные напоминания
отмечаются в базе: после перезапуска повторов не будет, а пропущенное (пока бот был выключен)
уйдёт при следующей проверке.

## Развёртывание на VPS (systemd)

Пример для Ubuntu/Debian. Команды выполняются от root или через `sudo`.

1. Установите Python и git, создайте пользователя для бота:
   ```bash
   apt update && apt install -y python3 python3-venv git
   useradd --system --create-home --shell /usr/sbin/nologin santa
   ```
2. Скачайте проект и установите зависимости:
   ```bash
   git clone https://github.com/vit3ma3/secret_santa_demo.git /opt/secret_santa_demo
   cd /opt/secret_santa_demo
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   cp .env.example .env
   nano .env            # впишите BOT_TOKEN
   chown -R santa:santa /opt/secret_santa_demo
   chmod 600 .env
   ```
3. Подключите сервис и запустите его:
   ```bash
   cp deploy/secret-santa-bot.service /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable --now secret-santa-bot
   ```
4. Проверка и логи:
   ```bash
   systemctl status secret-santa-bot
   journalctl -u secret-santa-bot -f
   ```

Обновление до новой версии:
```bash
cd /opt/secret_santa_demo
sudo -u santa git pull
sudo -u santa .venv/bin/pip install -r requirements.txt
systemctl restart secret-santa-bot
```

База (`santa.db`) лежит в папке проекта. Для резервной копии достаточно скопировать этот файл.
